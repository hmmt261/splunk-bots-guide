== はじめに

=== このガイドについて

本書は，Splunk 社が公開しているセキュリティ演習用データセット **Boss of the SOC (BOTS)** の v1・v2・v3 を使い，
演習環境（BOTS Lab）に出題されている全 98 問の解き方を解説するガイドである．

BOTS は，架空の企業で起きたインシデントのログ一式（Web アクセス，DNS，メール，Sysmon，Windows イベントログ，
osquery，AWS CloudTrail など）を Splunk に取り込んだものである．
受講者は SOC アナリストとしてログを読み，攻撃者が何をしたのかを順に明らかにしていく．

本書の各問題の解説は，次の資料をもとに作成した．

* 複数の解答者（AI エージェント 4 チーム）が実際に演習を解いたときの writeup
* 本書の執筆時に演習環境の Splunk で検索をやり直し，結果を確認したもの

writeup の間で手順や答えが食い違っていた箇所，誰も解けなかった問題は，Splunk で検証し直して書いた．

参考として，各 AI エージェントの正解数と所要時間を示す．
所要時間は，各 writeup に記録された最初の正解から最後の正解までの時間である．

=== 演習環境

演習環境は次の 2 つで構成されている．

Splunk Enterprise 9.2::
BOTS v1〜v3 の索引済みデータが `botsv1`・`botsv2`・`botsv3` の 3 つのインデックスに入っている．
受講者は検索専用のアカウントでログインする．
Sysmon，Symantec Endpoint Protection，Palo Alto Networks，Unix and Linux の各アドオンが入っている．

スコアサーバー（rCTF）::
問題文の確認と解答の提出を行う．
解答は前後の空白と大文字・小文字を区別せずに判定される．

.各インデックスのデータ期間
[cols="1,2,2", options="header"]
|===
|インデックス |イベント数 |データ期間（UTC）

|`botsv1` |約 3,300 万 |2016-08-01〜2016-08-29
|`botsv2` |約 2 億 2,600 万 |2017-08-01〜2017-09-01
|`botsv3` |約 200 万 |2018-08-20 前後（一部 2019 年まで）
|===

IMPORTANT: データは何年も前のものである．
Splunk の検索画面では，時間範囲を必ず **全時間（All time）** にすること．
既定の「過去 24 時間」のままでは何もヒットしない．

=== 必要な知識

* Splunk の基本的な検索（`index=`，`sourcetype=`，`stats`，`table`，`sort`）を使ったことがある
* HTTP，DNS，SMB，メール（SMTP）などのプロトコルの基礎
* Windows のプロセスとイベントログ，Linux のコマンドの基礎

Splunk の検索言語（SPL）に慣れていない場合は，先に <<chap_basics>> を読むとよい．

=== 表記のルール

* SPL，フィールド名，ファイル名は `等幅フォント` で示す．
* SPL は Splunk の検索バーにそのまま貼り付けて実行できる形で載せている．
  時間範囲は検索文に含めていないので，検索画面で「全時間」を選んでおくこと．
* 時刻は断りのない限り UTC で表記する．
  Splunk の表示タイムゾーンをアカウントの設定で UTC 以外にしている場合は，表示がずれるので注意．
* 問題文は演習環境に出題されている英文をそのまま引用する．
